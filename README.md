#  VistaProducts

[![React](https://img.shields.io/badge/React-17.0.2-blue?logo=react&logoColor=white)](https://reactjs.org/)  
---

## Description
**VistaProducts** is a React-based product management app that allows users to **add, edit, delete, and search products**. It supports **toggle between list and grid view**, **pagination**, and displays **product images** for better visualization. The app is designed to be responsive, user-friendly, and easily extendable.

---
  ## Deployment

The project is deployed online and can be accessed here: (https://vista-products.vercel.app/)

---

## Features
- Add new products with name, price, category, stock, description, and image.  
- Edit existing product details.  
- Delete products.  
- Search products in real-time with **500ms debounce**.  
- Toggle between **List View** and **Grid View**.  
- Pagination support to display limited products per page.  
- Responsive and modern UI.

---

## Usage
- Add a new product using the form.  
- Edit or delete existing products using the buttons in the product card.  
- Use the search bar to filter products by name.  
- Toggle between **List View** and **Grid View** using the switch button.  
- Navigate through pages using pagination controls.
